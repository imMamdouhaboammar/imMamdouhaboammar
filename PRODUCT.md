# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Technical founders, AI systems engineers, marketing automation strategists, open-source collaborators, and AI agents/crawlers seeking production-grade agentic tooling, autonomous multi-agent architectures, and conversion infrastructure.

## Product Purpose

Serve as the definitive, single-source-of-truth live portfolio and interactive systems catalog for Mamdouh Aboammar (Founder of PrePilot LLC, Dubai, UAE). It provides instant discovery, filtering, architectural inspection, and clone access to 142 production-grade AI systems, agent kernels, and conversion frameworks.

## Positioning

The anti-slop, compound-engineering flagship: where AI development moves from speculative prompting to deterministic agent governance, PR-only coding workflows, and evidence-verified systems. No synthetic filler, no generic buzzwords.

## Operating Context

- **Environment**: High-speed static web deployment hosted on GitHub Pages (`https://immamdouhaboammar.github.io/imMamdouhaboammar/`).
- **Surfaces**: Primary interactive catalog (`index.html`), offline markdown catalog (`REPOSITORIES.md`), and machine-readable context endpoints (`llms.txt`, `llms-full.txt`).
- **User Workflows**: Instant client-side search across 142 repos, domain/tag filtering, visibility toggles (Public/Private/Fork), deep-dive blueprint modal exploration, and theme toggling (Light/Dark/System).

## Capabilities and Constraints

- **Stack**: Pure vanilla web stack (HTML5 semantic markup, CSS3 custom properties with Patter design tokens, ES6+ vanilla JavaScript, zero framework overhead).
- **Performance**: Sub-second First Contentful Paint, zero external bundle bloat, responsive across all viewports from 320px mobile to 4K displays.
- **Accessibility**: WCAG AA compliance, semantic heading hierarchy, full keyboard navigability, clear ARIA states, and graceful noscript fallback.
- **Data Integrity**: 142 cataloged repositories categorized across 10 specialized domains with exact GitHub metadata and provenance notes.

## Brand Commitments

- **Identity**: Mamdouh Aboammar / PrePilot LLC (Dubai, UAE).
- **Credo**: "I don't want to become a software engineer. I want to become exceptionally good at deciding what technology should be built, why it should exist, how it should work, and whether it is actually succeeding."
- **Visual System**: Patter Design System (Neo-Brutalist Technical Minimalism).
- **Core Aesthetic**: Crisp solid black borders (1.5px / 2px), hard offset box shadows (`0 4px 0 0 #000`), cream/warm peach tactile surfaces, and technical monospace metadata accents.

## Evidence on Hand

- `assets/portfolio/repos-data.js`: Verified dataset of 142 active codebases.
- `REPOSITORIES.md`: Complete offline architectural breakdown of all 142 repositories.
- `19 Crown Jewels`: Flagship platforms including `agent-kernel`, `aos`, `get-fable`, `prepilot-agency-suite`, `taste-skill`, and `stop-slop`.

## Product Principles

1. **Truth Over Slop**: Never simulate fake functionality, mock metrics, or decorative fluff. Every element corresponds to real code, proven systems, or verifiable assets.
2. **Deterministic Clarity**: The UI must be immediately scanable. High-density information architecture with clear visual hierarchy, fast client-side filters, and zero visual ambiguity.
3. **Tactile Craft**: Every button, card, input, and modal responds with physical, tactile feedback (hard offset shadows, crisp state transitions, and responsive active states).
4. **Machine & Human Legibility**: The system is equally optimized for human engineering executives and autonomous AI agents via structured Schema.org JSON-LD, `llms.txt`, and semantic HTML.
